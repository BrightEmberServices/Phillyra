# Phillyra — Public Documentation

**Phillyra** is a private, on-device market forecaster for iPhone and iPad, built by
[BrightEmber](https://github.com/BrightEmberServices). It runs the open-source
[Kronos](https://github.com/shiyu-coder/Kronos) forecasting model entirely on your
device — no account, no servers, no tracking, and it's completely free.

## Documents

- **[Privacy Policy](https://brightemberservices.github.io/Phillyra/privacy-policy.html)** —
  the short version: nothing about you is collected, by construction.
